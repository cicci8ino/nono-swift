# Notices

This unofficial package wraps the upstream `nono` C FFI and follows the public behavior of `nono-go`. It is not maintained by, endorsed by, or affiliated with the upstream `nono` project.

Sources:

1. `https://github.com/always-further/nono`
2. `https://github.com/always-further/nono-go`

The generated `Artifacts/CNono.xcframework` is built from upstream `nono` source. Exact source commit and artifact checksums are recorded in `Artifacts/MANIFEST.json` when `make artifacts` is run.
